# JunctionHealing

This repository contains the code and computational models used in the manuscript **“[Emergent Tissue Stability from Intercellular Bond Dynamics during Cyclic Mechanical Loading](https://doi.org/10.1016/j.bpj.2026.06.038)”** (Papafilippou *et al.*, 2026). It provides scripts for setting up dependencies, running simulations, and reproducing all results presented.

[![DOI](https://zenodo.org/badge/1114612330.svg)](https://doi.org/10.5281/zenodo.21777729)

## Contents

- **`setup_libraries.jl`** – installs all required Julia dependencies.  
- **`Figure_X.ipynb`** – Jupyter notebooks used to run simulations and generate each figure.  
- Additional source files supporting the modelling and visualisations.

## Getting Started

### 1. Install Julia

Download and install Julia by following the official instructions:

<https://julialang.org/downloads/>

Ensure that Julia is added to your system path, or launch it via the Julia executable.

### 2. Set Up the Required Libraries

From the repository root, run:

```julia
julia setup_libraries.jl
````

This will install all dependencies needed to run the notebooks and scripts.

### 3. Reproduce the Results

All results shown in the manuscript can be generated by running the notebooks.
